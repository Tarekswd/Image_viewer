# Image_viewer
Image Viewer in C language , inspired by the one made by Daniel Hirsch on Youtube!  

Make sure the image format is ppm!
## How to use  

First install SDL3 library :  

Open the MSYS2 MINGW64 terminal and install SDL3:  


pacman -S mingw-w64-x86_64-SDL3  

then compile  

gcc iv.c -lSDL3 -o viewer(u can name it something else)  

 finally choose the image u want to viewe  
 
 this is an example:  
 
 viewer < usopp.ppm
